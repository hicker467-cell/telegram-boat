## 🚀 Cloud Deployment (24/7 Free)

### Deploy on Render / Koyeb:
1. Fork or push this repository to GitHub: `https://github.com/hicker467-cell/telegram-boat.git`
2. Go to **[Render.com](https://render.com)** -> Create New -> **Background Worker**.
3. Connect your GitHub repository `telegram-boat`.
4. Set Build Command: `pip install -r requirements.txt`
5. Set Start Command: `python bot.py`
6. Click **Deploy**. The bot will run 24/7 in the cloud without needing your PC to stay on!
